# Simulador de Exámenes Interactivos / Proyecto Android Test Ace
Nuestra app tiene como objetivo ayudar a estudiantes a practicar y evaluar sus conocimientos mediante exámenes interactivos de distintas materias y niveles educativos.
Se le permitiría a los usuarios resolver evaluaciones en un entorno dinámico, obtener resultados inmediatos y recibir retroalimentación sobre su desempeño.
Este proyecto surge como respuesta a la necesidad de contar con herramientas accesibles que permitan una práctica activa y efectiva, reduciendo la incertidumbre y el estrés al momento de rendir evaluaciones reales.

## Público objetivo: 
Estudiantes y personas en proceso de aprendizaje autodidacta

## Tecnologías utilizadas: 
### Back: Java, Android SDK, Django y 'Gradle' (Build/Compilación)
### Front: xml
### BD: MySQL

## Funcionalidades

- Pantalla Splash
- Navegación por la app
- Pantalla para registrarse
- Pantalla para iniciar sesión
- Pantalla de catálogo de exámenes / Poder buscar y filtrar exámenes
- Vista previa para exámenes
- Pantalla de intento de examen
- Pantalla de resultado de examen
- Pantalla donde ver y editar tu perfil
- Pantalla donde ver tus exámenes realizados recientes
- Pantalla de contacto
